# Alina — AI-консультант для ВКонтакте

Интеллектуальный чат-бот для сообществ ВКонтакте, который консультирует пользователей по образовательным программам университета **Zerocoder**. Построен на базе GigaChat API с использованием базы знаний и контекстной памяти диалогов.

## Живой пример

Бот работает в сообществе ВКонтакте — напишите сообщение сообществу и получите консультацию от Алины.

## Архитектура

```
Пользователь (VK)
       │
       ▼
  VkCommunityBot          ← Bots Long Poll, история диалогов
       │
       ▼
  GigaChatClient           ← OAuth-токен + chat/completions API
       │
       ▼
  KnowledgeBase            ← Markdown-файлы → секции → контекст промпта
       │
       ▼
  System Prompt (Алина)    ← Персона + правила + база знаний
```

**Ключевые особенности:**

- **Bots Long Poll** — не нужен внешний сервер и вебхуки; бот слушает события ВК напрямую
- **Контекстная память** — хранит историю переписки по каждому собеседнику (настраиваемое окно)
- **База знаний** — markdown-файлы, парсятся автоматически; добавление новой информации = редактирование `.md`
- **Автоматическое обновление токена** — access-токен GigaChat (30 мин) обновляется без участия пользователя
- **Умное разбиение** — длинные ответы автоматически разбиваются на части с учётом словоразрывов

## Быстрый старт

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/Tugarin9999/ZeroTest.git
cd ZeroTest
```

### 2. Создайте виртуальное окружение

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Настройте переменные окружения

```bash
cp .env.example .env
```

Откройте `.env` и заполните обязательные значения:

| Переменная | Описание | Где взять |
| --- | --- | --- |
| `VK_GROUP_TOKEN` | Токен сообщества ВК с правом «Сообщения» | VK → Управление → Работа с API → Ключи доступа |
| `GIGACHAT_AUTH_KEY` | Ключ авторизации GigaChat | Studio → GigaChat API → Настройки API → Получить ключ |

### 5. Запустите бота

```bash
python main.py
```

Бот начнёт слушать сообщения сообщества. Напишите сообщество в личные сообщения — Алина ответит.

## База знаний

База знаний — это markdown-файлы в папке `knowledge_base/`. Каждый заголовок `##` становится отдельной секцией.

**Как добавить информацию:**

1. Откройте `knowledge_base/zerocoder.md` (или создайте новый `.md` файл)
2. Добавьте секцию с заголовком `##`
3. Перезапустите бота

**Режим ретрива:**

- По умолчанию бот передаёт моделью всю базу целиком
- Если задать `KNOWLEDGE_TOP_K=N` в `.env`, бот будет подставлять только `N` наиболее релевантных секций по ключевым словам запроса (экономит токены)

## Конфигурация

Все настройки задаются через `.env`. Полный список см. в `.env.example`.

Ключевые параметры:

- `GIGACHAT_MODEL` — выбор модели (по умолчанию `GigaChat-2-Pro`)
- `MAX_HISTORY_MESSAGES` — размер окна памяти диалога (по умолчанию 12)
- `MAX_REPLY_LENGTH` — максимум символов в одном сообщении ВК (по умолчанию 3800)
- `KNOWLEDGE_TOP_K` — количество релевантных секций базы знаний (пусто = вся база)

## Безопасность

- Секреты хранятся только в `.env` — в код не вшиты
- `.env` добавлен в `.gitignore` — не попадает в Git
- Код не логирует токены и ключи авторизации
- Файл `.env.example` содержит только имена переменных
